# TreatmentCard

Card de tratamento com ícone de linha dourado, título serifado, uma frase de benefício e link editorial.

- Tratamentos do Instagram: Harmonização facial, Rejuvenescimento 40+, K-Beauty / estética regenerativa, Harmonização corporal.
- Texto: benefício em uma frase, sem jargão técnico e sem promessa de resultado.
- Grade de 3 (desktop) / carrossel com snap (mobile). Hover: sobe 6px com `shadow-lift`.
- Variante com foto: troque o ícone por imagem 4:3 com `radius-md` no topo.
