# StatBlock

Números de autoridade em Cormorant dourado (`gold`, 64px) com rótulo em `ink-muted`, separados por fios `hairline`.

- Números reais da bio e da imprensa: +25 mil atendimentos, 9 anos de experiência, 8 anos de clínica, AMWC Coreia 2026.
- Contam de 0 ao entrar na tela, uma vez (1.4s, `power2.out`).
- `gold` só em 32px+; em fundo `surface-inverse` use `brand-champagne`.
