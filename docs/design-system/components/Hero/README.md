# Hero

A primeira dobra: headline serifada com itálico, promessa 40+, dois CTAs, foto em arco da Dra. e prova social flutuante.

- Grid 5/6 colunas; no mobile a foto vem primeiro (arco com 70vh) e o texto abaixo.
- Headline fixa da marca: "Rejuvenescer sem deixar de *ser você.*" (alternativa: "Seu rosto mais jovem. *Sua identidade intacta.*").
- O consumidor fornece a foto real (4:5, ver Fotografia). Badge "+25 mil" com contador; assinatura em Pinyon Script (ou SVG da assinatura real).
- Animação: título por linhas, arco revelado por clip-path + escala 1.12→1, badge e assinatura com parallax oposto (ver Movimento).
