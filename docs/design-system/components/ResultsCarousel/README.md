# ResultsCarousel

Cards de foto 3:4 deslizando em loop infinito — o "elas testaram e não vivem sem" da Glyze, adaptado para resultados e bastidores.

- Conteúdo: resultados autorizados, pacientes na recepção, bastidores, matérias de imprensa. Cada card com legenda curta ("Lábios · 1 sessão").
- 60s por volta, pausa no hover, card sobe 8px com `shadow-lift`. Desktop: duas fileiras em sentidos opostos (`lt-reel--reverse`).
- Clique abre lightbox com a foto grande e a legenda completa + disclaimer "resultados variam de pessoa para pessoa".
- Placeholders aqui; o consumidor fornece as fotos (ver Fotografia).
