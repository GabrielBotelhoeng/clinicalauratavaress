# Button

Pílulas em caixa alta espaçada; a primária (`lt-btn--primary`, `accent`) é a única ação de conversão.

- **primary** — "Agendar avaliação". Uma por dobra. Hover: preenchimento `accent-hover` desliza da esquerda e a seta avança 4px.
- **outline** — ação secundária ao lado da primária ("Ver tratamentos").
- **whatsapp** — só onde o clique abre o WhatsApp direto (`whatsapp` / `on-whatsapp`).
- **ghost** — link editorial dentro de texto e cards.
- `lt-btn--sm` (44px) no header e no mobile.

Rótulos: verbo + objeto, até 3 palavras. Nunca "Clique aqui" ou "Compre". Em seções `noite` os tokens já invertem sozinhos.
