# BeforeAfter

Comparador arrastável de antes e depois — o componente que mais converte em estética, com acessibilidade por teclado.

- Estrutura: duas camadas de imagem empilhadas; a de "depois" é recortada com `clip-path: inset(0 0 0 var(--pos))`; um `input range` invisível cobre tudo (arraste, toque e setas do teclado).
- Fotos: mesma luz, ângulo, distância, sem maquiagem e sem filtro; 4:5. O consumidor fornece os pares e o termo de autorização de imagem.
- Legenda obrigatória: procedimento, nº de sessões e "Resultados variam de pessoa para pessoa".
- Ao entrar na tela pela 1ª vez, a alça faz uma demonstração automática (50→30→70→50%).
- Em grade, use abas por procedimento (Lábios, Olheiras, Mandíbula, Rejuvenescimento).
