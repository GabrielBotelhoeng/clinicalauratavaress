# Navbar

Header em pílula flutuante (`surface-raised`, `radius-pill`, borda `hairline`) que fica fixo a 16px do topo.

- Marca: monograma LT oficial quando a clínica enviar o SVG; até lá, wordmark "Laura Tavares" (Cormorant 500) + `eyebrow` "Estética Avançada".
- Ao rolar para baixo, esconde (translateY -120%); ao rolar para cima, reaparece — `ease-lux`, `dur-base`.
- Mobile: marca + botão "Agendar" pequeno + menu em tela cheia `surface-blush` com links em Cormorant 40px.
